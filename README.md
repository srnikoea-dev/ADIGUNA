# Arsip Guru

Aplikasi Android **offline** untuk arsip digital guru.

- Kategori dokumen yang bisa dikustomisasi (nama, ikon, warna)
- Scan dokumen (crop otomatis, multi-halaman, hasil PDF) via ML Kit Document Scanner
- Impor file apa pun (PDF, Word, Excel, gambar, dll.)
- Bagikan satu atau banyak dokumen sekaligus (WhatsApp, Email, Drive, dll.)
- Cari, ganti nama, pindah kategori, hapus
- Tanpa izin internet; semua berkas tersimpan privat di penyimpanan internal aplikasi

## Cara mendapatkan APK
1. Upload semua isi folder ini ke repo GitHub (branch `main`).
2. Buka tab **Actions** -> workflow **Build APK** (jalan otomatis saat push, atau klik *Run workflow*).
3. Setelah selesai, unduh artifact **ArsipGuru-APK** -> `app-debug.apk`, lalu install di HP.

Persyaratan HP: Android 8.0+ dan Google Play Services (untuk fitur scan).
